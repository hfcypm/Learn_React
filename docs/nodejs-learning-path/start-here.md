# Node.js 新手导读

## 适合谁

这套路线适合已经会 JavaScript、TypeScript 和基本前端开发，准备第一次系统学习服务端开发的人。学习重点是理解 Node.js 如何运行，再逐步建立 Web 服务、数据层、测试和生产交付能力。

## 开始前准备

- 能够使用变量、函数、对象、数组、Promise 和 `async/await`。
- 能读懂 TypeScript 类型、泛型和模块导入。
- 能使用终端、Git、JSON 和 HTTP 基本概念。
- 安装受支持的 Node.js LTS、npm 和编辑器。

```bash
node --version
npm --version
```

## 学习顺序

| 阶段 | 先回答的问题 | 阶段产出 |
| --- | --- | --- |
| 零 | Node.js 如何执行代码和处理异步任务？ | 命令行脚本和文件读取工具 |
| 一 | 如何使用原生 API 接收和返回 HTTP？ | 带 `/health` 的 HTTP 服务 |
| 二 | 如何组织业务、校验输入和访问数据？ | 分层用户 API |
| 三 | 如何证明服务可靠并处理并发？ | 测试、日志和后台任务 |
| 四 | 如何让服务安全、可观测、可部署？ | 容器化和生产检查清单 |

## 每阶段学习方法

1. 先阅读阶段目标和验收项。
2. 只学习完成当前阶段任务所需的主题。
3. 运行最小代码，主动制造一次错误并观察处理结果。
4. 完成阶段项目增量，再进入下一阶段。
5. 用自己的话回答阶段问题，并保留命令输出或测试结果。

## 常见排错顺序

```text
Node.js 版本
  -> package.json 与工作目录
  -> ESM/CommonJS 配置
  -> 导入路径和文件扩展名
  -> 请求方法、路径和 Content-Type
  -> 输入校验与错误映射
  -> 数据库连接与迁移
  -> 测试、日志和进程退出
```

## 阶段项目路线

从 [综合实战：用户管理 API](./project-practice.md) 开始，每完成一个阶段就增加一个能力：健康检查、用户 CRUD、认证授权、测试观测和部署。文档中的片段用于理解关键边界，完整项目需要按章节补齐依赖和文件。

## 完成标准

- 能从零解释一个 Node.js 服务的启动、请求、业务和数据流。
- 能为外部输入设置校验、超时、取消和统一错误响应。
- 能使用测试、日志、健康检查和配置管理支持维护。
- 能在部署前完成安全、迁移、优雅退出和回滚检查。
