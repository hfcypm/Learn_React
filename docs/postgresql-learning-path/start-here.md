# PostgreSQL 新手导读

## 适合谁

这套路线适合已经了解一种编程语言，准备系统掌握关系数据库的开发者。学习重点是理解关系模型和 SQL，再逐步掌握数据建模、索引、事务和生产运维。

## 开始前准备

- 会使用终端命令行。
- 了解一种编程语言的变量、数组和函数概念。
- 理解 JSON 数据结构（便于理解 JSONB）。
- 了解 Web 应用如何通过连接串访问数据库。

```bash
psql --version
```

没有安装 PostgreSQL 时，使用系统包管理器安装，或使用 Docker：

```bash
docker run -d --name pg17 -e POSTGRES_PASSWORD=postgres -p 5432:5432 postgres:17
```

## 学习顺序

| 阶段 | 先回答的问题 | 阶段产出 |
| --- | --- | --- |
| 零 | 如何安装、连接并操作一个数据库？ | 可连接的本地数据库 |
| 一 | 如何用 SQL 查询、聚合和关联数据？ | 可用的查询语句集 |
| 二 | 如何设计表结构、约束和索引？ | 规范化且完整的数据模型 |
| 三 | 如何保证并发正确性和查询性能？ | 带索引和事务的生产查询 |
| 四 | 如何备份、监控和扩展数据库？ | 可靠的生产数据库方案 |

## 每阶段学习方法

1. 每个概念先写最小 SQL 并实际运行，观察结果。
2. 故意写错 SQL，阅读错误信息理解语义。
3. 查询慢时用 EXPLAIN 分析，再改索引或写法。
4. 用示例数据填充表，验证约束和索引行为。

## 常见排错顺序

```text
连接与权限
  -> 表和列名、大小写与引号
  -> 数据类型不匹配
  -> SQL 语法和 JOIN 方向
  -> 聚合与 GROUP BY
  -> 事务与锁冲突
  -> 索引是否被使用
  -> 备份与恢复
```

## 阶段项目路线

从 [综合实战：电商订单数据库](./project-practice.md) 开始，每完成一个阶段就增加一个能力：建库建表、查询分析、数据建模、索引优化和生产运维。

## 完成标准

- 能安装并连接 PostgreSQL，完成基础 DDL 和 DML。
- 能写出正确的 JOIN、聚合和窗口查询。
- 能设计范式合理、约束完整的数据模型。
- 能用 EXPLAIN 优化慢查询并解释索引选择。
- 理解事务隔离、锁和备份恢复机制。
- 完成 [学习评估](./learning-assessment.md) 中的阶段考核与项目评分。
