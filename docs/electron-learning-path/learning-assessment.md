# Electron 学习评估与项目评分

**目标**：通过概念、编码、排错和项目评审确认学习者是否真正掌握了 Electron 的进程模型、IPC、系统集成与打包发布，避免只记住 API 名称。

## 1. 阶段考核

### 阶段零：基础与工具链

- 解释主进程、渲染进程、preload 的职责。
- 初始化项目并运行第一个窗口。
- 理解 `ready`、`window-all-closed`、`activate` 生命周期。

### 阶段一：进程模型与 IPC

- 用 preload + contextBridge 暴露安全 API。
- 用 `ipcMain.handle` / `ipcRenderer.invoke` 完成请求响应。
- 用 `webContents.send` 推送主进程事件。
- 说明 `contextIsolation` 与 `sandbox` 的作用。

### 阶段二：窗口与系统集成

- 创建多窗口并实现窗口间通信。
- 构建菜单、托盘与系统通知。
- 用对话框与 shell 完成系统交互。

### 阶段三：文件、数据与前端集成

- 使用 `app.getPath` 正确选择存储目录。
- 主进程完成文件读写并封装 IPC。
- 集成前端框架构建渲染进程。

### 阶段四：打包发布与生产

- 用 electron-builder 打包三平台产物。
- 配置代码签名与自动更新。
- 复查安全基线并执行发布流程。

## 2. 排错题

- 窗口白屏或加载失败。
- preload 未生效导致 API 缺失。
- IPC 通道名不匹配。
- 上下文隔离与沙箱冲突。
- 系统路径写错导致数据丢失。
- 文件名路径穿越。
- 打包缺少文件或无法启动。
- 自动更新不生效。
- 签名失败或被系统拦截。

## 3. 项目评分

总分 100 分，70 分通过，90 分优秀。参考 [综合实战：桌面笔记应用](./project-practice.md)：

| 维度 | 分值 | 评分重点 |
|---|---:|---|
| 进程与 IPC | 25 | preload 安全暴露、通道设计、双向通信 |
| 系统集成 | 20 | 多窗口、菜单、托盘、通知、对话框 |
| 数据与持久化 | 20 | 系统路径、文件读写、设置持久化 |
| 安全 | 15 | 隔离、沙箱、入参校验、无 nodeIntegration |
| 工程化 | 20 | 构建、打包、签名、自动更新、发布清单 |

## 4. 项目评审问题

- 为什么渲染进程不能直接使用 Node 与系统 API？
- preload 暴露 API 的最小化原则如何落地？
- IPC 通道如何命名与校验入参？
- 何时用 invoke/handle，何时用 send/on，何时用 webContents.send？
- 多窗口之间如何安全通信？
- 数据应该存在哪个目录，为什么？
- 打包后资源路径与开发环境有何差异？
- 自动更新如何保证安装包与元数据一致？
- 如何审查一个 Electron 应用的安全基线？
