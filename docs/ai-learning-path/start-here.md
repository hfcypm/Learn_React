# AI 应用前端新手导读

## 适合谁

这套路线适合已经掌握 HTML、CSS、JavaScript、TypeScript、React 和 Next.js 基础，准备把前端能力用于 AI Chat、AI Agent 和数据密集型应用的人。学习重点是理解 AI 应用前端的数据流、实时通信和内容渲染。

## 开始前准备

- 能使用 React 组件、Hooks、表单和条件渲染。
- 能读懂 TypeScript 接口、联合类型、泛型和类型收窄。
- 能解释 HTTP 方法、状态码、JSON 和 Promise。
- 能在 Next.js 中配置路由、环境变量和 API 请求。

```bash
node --version
npm --version
```

## 学习顺序

| 阶段 | 先回答的问题 | 阶段产出 |
| --- | --- | --- |
| 一 | 如何管理服务端数据、缓存和加载状态？ | TanStack Query 驱动的列表与缓存 |
| 二 | 会话、草稿和跨组件状态放哪里？ | Zustand 管理的会话与 UI 状态 |
| 三 | 流式回答如何逐字展示并支持停止与重试？ | SSE/WebSocket/流式响应页面 |
| 四 | 文件、Markdown、代码和图表如何渲染？ | 文件上传与内容渲染组件 |

## 每阶段学习方法

1. 先理解数据流，再运行最小示例。
2. 每个示例都观察加载、成功、空数据、失败和取消状态。
3. 综合案例先完成静态界面，再接入普通请求，最后接入流式响应。
4. 所有用户输入、文件类型、文件大小和服务端返回内容都进行校验。

## 常见排错顺序

```text
网络请求是否到达
  -> 请求方法、URL 和 Content-Type
  -> 状态码与错误响应
  -> 缓存命中与失效策略
  -> 流式响应的读取与取消
  -> Markdown/代码/图表渲染失败
  -> 组件状态与全局状态边界
```

## 阶段项目路线

从 [AI 学习工作台综合案例](./project-practice.md) 开始，按"静态界面 -> 普通请求 -> 流式响应 -> 内容渲染"的顺序逐步扩展。模型服务、文件解析和 Agent 编排先使用 Mock API，之后替换为真实服务。

## 完成标准

- 能区分服务端状态、客户端状态和 URL 状态。
- 能实现逐字流式回答、停止生成、重试和错误恢复。
- 能安全处理文件上传，并渲染 Markdown、代码和图表。
- 能独立设计一个 AI Chat 或 AI Agent 的前端页面。
- 完成 [学习评估](./learning-assessment.md) 中的阶段考核与项目评分。
