# LangChain 学习评估与项目评分

**目标**：通过概念、编码、排错和项目评审确认学习者是否真正掌握了 LangChain 的模型接入、LCEL 组合、RAG 与 Agent，避免只记住 API 名称。

## 1. 阶段考核

### 阶段零：基础与工具链

- 解释 Runnable 与 LCEL 的角色。
- 初始化项目并正确配置模型 Key。
- 用 `.pipe()` 组合提示、模型与解析器。
- 用 `invoke`、`batch`、`stream` 三种方式调用链。

### 阶段一：模型与提示词

- 区分 System、Human、AI 三种消息角色。
- 用 PromptTemplate 与 ChatPromptTemplate 组织提示。
- 用 `MessagesPlaceholder` 注入历史消息。
- 用 zod Schema 约束结构化输出。

### 阶段二：LCEL 链与检索增强

- 用 RunnableParallel 并行执行多个分支。
- 加载、切分文档并建立向量索引。
- 组装完整的 RAG 链。
- 说明切分参数对检索质量的影响。

### 阶段三：Agent 与工具

- 用 `tool()` 定义带 Schema 的工具。
- 用 `createAgent` 创建可自主调用工具的 Agent。
- 用 `streamEvents` 观察工具调用过程。
- 说明链与 Agent 的使用边界。

### 阶段四：生产化交付

- 用 checkpointer 与 `thread_id` 实现会话记忆。
- 实现流式输出与长对话压缩。
- 配置超时、重试与回退。
- 用 LangSmith 追踪并定位问题。

## 2. 排错题

- 模型 Key 缺失或配置错误。
- 消息角色或提示模板变量缺失。
- 结构化输出与 Schema 不匹配。
- LCEL 链类型不匹配。
- 向量检索结果为空或相关度差。
- 工具从未被调用或参数抽取错误。
- 多轮记忆丢失。
- 流式输出被缓冲或超时。
- 回退未生效。

## 3. 项目评分

总分 100 分，70 分通过，90 分优秀。参考 [综合实战：知识库客服机器人](./project-practice.md)：

| 维度 | 分值 | 评分重点 |
|---|---:|---|
| 提示与结构化输出 | 15 | 模板组织、Schema 约束、输出解析 |
| RAG 质量 | 20 | 切分、检索相关度、答案忠实度 |
| 工具与 Agent | 25 | 工具设计、Schema、多步推理正确性 |
| 记忆与流式 | 20 | 会话隔离、压缩、流式呈现 |
| 工程化 | 20 | 回退、超时、追踪、部署与密钥安全 |

## 4. 项目评审问题

- 什么场景用链，什么场景用 Agent？
- 检索增强相比把文档塞进提示词有哪些优势？
- 如何评估 RAG 的检索质量与答案质量？
- 工具 Schema 如何设计才能让参数抽取稳定？
- 如何保证多轮对话不串会话？
- 流式输出如何控制错误与重试？
- 长对话如何控制 token 成本？
- 生产环境如何追踪一次完整调用？
- 模型 Key 如何安全管理？
