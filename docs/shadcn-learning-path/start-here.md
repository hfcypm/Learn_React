# shadcn/ui 新手导读

## 适合谁

这套路线适合已经掌握 React 与 Tailwind CSS，准备用一套高质量、可访问、可定制的组件快速搭建界面（中后台、Dashboard、表单密集型应用）的开发者。学习重点是组件分发模式、主题定制、复杂组件与工程化。

## 开始前准备

- 掌握 React 组件、Hooks、Props 与 TypeScript 基础，可参考 [React 学习路线](../react-learning-path/README.md) 与 [TypeScript 学习路线](../typescript-learning-path/README.md)。
- 掌握 Tailwind CSS 工具类与主题机制，可参考 [Tailwind CSS 学习路线](../tailwindcss-learning-path/README.md)。
- 了解一个支持 Tailwind 的构建工具链（Vite 或 Next.js）。
- 能运行 Node.js 与 npm。

```bash
node --version
npm --version
```

## 核心观念

shadcn/ui 把组件源码（而不是编译好的包）放进你的项目。这意味着：

- 组件不是第三方依赖，而是你自己的代码，可任意修改。
- 组件与项目样式体系（Tailwind、CSS 变量）天然一致。
- 升级由你掌控，不跟随上游发版。

## 学习顺序

| 阶段 | 先回答的问题 | 阶段产出 |
| --- | --- | --- |
| 零 | 如何初始化并添加组件？ | 含首个组件的项目 |
| 一 | 如何理解并定制主题？ | 主题统一、暗色可切换的界面 |
| 二 | 如何实现对话框与表单？ | 交互完整、带校验的表单 |
| 三 | 如何展示表格与图表？ | 数据驱动的后台页面 |
| 四 | 如何工程化并生产交付？ | 可维护、可访问、可测试的应用 |

## 每阶段学习方法

1. 每个概念先在官方组件页看用法，再 `npx shadcn add` 到项目并实际运行。
2. 添加组件后阅读生成的源码，理解它依赖了哪些 Radix 组件与工具函数。
3. 从阶段一就改 CSS 变量而非逐个覆盖组件。
4. 为综合实战项目逐步添加能力，每个阶段验收后再继续。
5. 用键盘与屏幕阅读器验证默认可访问性。

## 常见排错顺序

```text
安装与初始化
  -> components.json 配置
  -> CSS 变量与主题未生效
  -> 组件未安装直接导入
  -> 别名路径错误
  -> 表单校验不触发
  -> 暗色模式不切换
  -> 服务器组件与客户端组件混用
```

## 阶段项目路线

从 [综合实战：订阅管理后台](./project-practice.md) 开始，每完成一个阶段就增加一个能力：初始化、主题、表单交互、数据表格与生产交付。

## 完成标准

- 能初始化并添加组件。
- 能用 CSS 变量定制主题与暗色模式。
- 能实现对话框、下拉与表单校验。
- 能实现数据表与图表。
- 能修改组件变体并保证可访问性。
- 完成 [学习评估](./learning-assessment.md) 中的阶段考核与项目评分。
