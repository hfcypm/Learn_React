# shadcn/ui 学习评估与项目评分

**目标**：通过概念、编码、排错和项目评审确认学习者是否真正掌握了 shadcn/ui 的组件分发、主题定制、交互表单与数据展示，避免只会机械地复制官方示例。

## 1. 阶段考核

### 阶段零：基础与工具链

- 解释组件源码分发模式与组件依赖模式的区别。
- 初始化并配置 components.json。
- 添加组件并正确导入使用。

### 阶段一：核心组件与主题

- 使用基础组件并理解 variant。
- 解释 CSS 变量主题机制。
- 定制主题色与暗色模式。

### 阶段二：交互组件与表单

- 使用 Dialog、DropdownMenu、Select。
- 用 react-hook-form + zod 实现校验表单。
- 组合对话框与表单。

### 阶段三：数据展示与状态

- 用 TanStack Table 实现排序、筛选、分页。
- 在列内渲染复杂内容。
- 用 Chart 组件实现图表。
- 处理空态与加载态。

### 阶段四：工程化与生产

- 读懂并修改 cva 变体。
- 维护可访问性基线。
- 搭建 Sidebar 布局。
- 为组件写交互测试。

## 2. 排错题

- init 或 add 失败。
- 组件导入与别名问题。
- 主题变量不生效。
- 暗色模式不切换。
- 表单校验不触发。
- 表格排序或分页失效。
- 图表不显示或颜色不变。
- Radix 组件在测试中报错。
- Server Component 中交互组件报错。

## 3. 项目评分

总分 100 分，70 分通过，90 分优秀。参考 [综合实战：订阅管理后台](./project-practice.md)：

| 维度 | 分值 | 评分重点 |
|---|---:|---|
| 主题定制 | 20 | CSS 变量、暗色、语义色一致 |
| 表单与交互 | 25 | Schema 校验、对话框、Select 正确性 |
| 数据展示 | 25 | 表格排序分页、徽章、图表、空/加载态 |
| 可访问性与质量 | 15 | 键盘操作、ARIA、对比度、变体扩展 |
| 工程化 | 15 | 测试、别名、组件组织、可维护性 |

## 4. 项目评审问题

- 组件放进项目与作为依赖安装各有何取舍？
- 主题为什么用 CSS 变量而不是逐组件覆盖？
- 改主题时哪些变量需要同时维护浅色与暗色？
- react-hook-form 与 zod 如何分工？
- 对话框内嵌表单的提交后行为如何设计？
- TanStack Table 的状态由谁管理，何时受控提升？
- 图表颜色如何跟随主题？
- 给组件新增变体是改源码还是包一层，为什么？
- 如何验证一个 shadcn 对话框的可访问性？
