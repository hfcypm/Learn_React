# Tailwind CSS 学习评估与项目评分

**目标**：通过概念、编码、排错和项目评审确认学习者是否真正掌握了 Tailwind CSS 的工具类、主题、响应式、组件化和工程化，避免只记住类名。

## 1. 阶段考核

### 阶段零：工具链与基础

- 解释 utility-first 与组件 CSS 的区别。
- 解释 Tailwind 扫描与按需生成的机制。
- 配置 Tailwind 并接入一个框架。
- 用开发者工具确认工具类生成的 CSS。

### 阶段一：核心概念与布局

- 用 flex 和 grid 完成常见布局。
- 解释间距刻度和颜色系统的设计。
- 完成导航、卡片、表单、表格等常见组件。

### 阶段二：响应式、主题与交互

- 使用断点前缀构建移动优先的响应式布局。
- 配置并实现暗色模式（系统跟随与手动切换）。
- 使用 hover、focus、disabled 等状态变体。

### 阶段三：组件化与进阶模式

- 将重复工具类组合抽取为组件并管理变体。
- 使用 @theme 定义和覆盖主题变量。
- 使用 @apply 和插件扩展样式能力。

### 阶段四：工程化与生产交付

- 控制生产 CSS 体积并解释构成。
- 保证焦点、对比度和语义化等无障碍。
- 配置视觉回归和组件测试。

## 2. 排错题

- 样式完全没有生效。
- 动态拼接类名导致工具类丢失。
- 断点不生效，小屏样式被大屏覆盖。
- dark 变体不跟随系统或手动切换。
- @apply 报错或使用不存在的类。
- 自定义颜色没有生成工具类。
- 生产 CSS 体积过大。
- 键盘无法看到焦点轮廓。
- 文字对比度不足。

## 3. 项目评分

总分 100 分，70 分通过，90 分优秀。参考 [综合实战：后台管理界面](./project-practice.md)：

| 维度 | 分值 | 评分重点 |
|---|---:|---|
| 布局实现 | 20 | flex/grid、间距、响应式 |
| 主题一致性 | 20 | 设计变量、暗色模式、语义颜色 |
| 组件化 | 15 | 变体管理、复用、类名组织 |
| 交互与状态 | 15 | 状态变体、过渡、动画 |
| 无障碍 | 10 | 焦点、对比度、语义化 |
| 工程化 | 10 | 体积控制、构建、扫描配置 |
| 测试质量 | 10 | 组件测试、视觉回归的有效性 |

## 4. 项目评审问题

- 为什么选择工具类而非自定义 CSS，边界在哪里？
- 颜色、字体、间距如何统一？魔法值如何避免？
- 组件变体如何管理，扩展新变体的成本是多少？
- 响应式默认值如何选择，为什么移动优先？
- 暗色模式如何保证所有状态都被覆盖？
- 如何控制生产 CSS 体积？
- 哪些交互依赖 hover，触屏用户如何操作？
- 如何验证布局在目标设备和断点下正确？
