# Tailwind CSS 新手导读

## 适合谁

这套路线适合已经掌握 HTML 和基础 CSS，准备用一种高效、一致的方式构建界面的开发者。学习重点是理解 utility-first 的思想，再逐步掌握布局、主题、响应式和工程化。

## 开始前准备

- 能写 HTML 标签、属性和嵌套结构。
- 理解 CSS 选择器、盒模型、flex 和 grid 基础。
- 能使用终端和 npm。
- 了解所在框架（React、Vue 或 Next.js）的基本用法。

```bash
node --version
npm --version
```

## 学习顺序

| 阶段 | 先回答的问题 | 阶段产出 |
| --- | --- | --- |
| 零 | Tailwind 如何安装、扫描和生成样式？ | 可运行的最小项目 |
| 一 | 如何用工具类完成布局、间距和排版？ | 静态页面卡片与导航 |
| 二 | 如何做响应式、暗色模式和交互状态？ | 适配多种屏幕的界面 |
| 三 | 如何抽取组件、定制主题、减少重复？ | 可复用的组件库雏形 |
| 四 | 如何控制体积、保证一致和无障碍？ | 优化并可交付的界面 |

## 每阶段学习方法

1. 先理解工具类生成机制，再记忆常用类名。
2. 每个概念先写最小示例，再放进综合项目。
3. 主动修改一个断点、颜色和状态类，观察变化。
4. 用浏览器开发者工具检查生成后的 CSS。

## 常见排错顺序

```text
安装与构建工具
  -> @import "tailwindcss" 是否正确
  -> 类名是否被扫描（文件内容、框架内容配置）
  -> 工具类拼写和层叠优先级
  -> 断点前缀与移动优先
  -> 主题变量是否生效
  -> 构建产物大小与无用类
```

## 阶段项目路线

从 [综合实战：后台管理界面](./project-practice.md) 开始，每完成一个阶段就增加一个能力：布局骨架、数据卡片、响应式表单、主题切换、组件抽取和体积优化。

## 完成标准

- 能使用工具类完成常见界面布局和样式。
- 能配置断点、暗色模式和状态变体。
- 能通过 @theme 定制主题并抽取复用样式。
- 能控制构建体积并保证基本无障碍。
- 完成 [学习评估](./learning-assessment.md) 中的阶段考核与项目评分。
