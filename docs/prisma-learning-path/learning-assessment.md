# Prisma 学习评估与项目评分

**目标**：通过概念、编码、排错和项目评审确认学习者是否真正掌握了 Prisma 的 Schema 建模、迁移、类型安全查询和工程化，避免只记住 API 名称。

## 1. 阶段考核

### 阶段零：基础与工具链

- 解释 Schema、Client、Migrate 的角色。
- 初始化项目并正确配置连接串。
- 生成迁移并创建表。
- 用 PrismaClient 完成一次写入和读取。

### 阶段一：Schema 数据建模

- 用 Schema 定义模型和标量类型。
- 实现一对一、一对多、多对多和自引用关系。
- 使用枚举、唯一约束和复合主键。

### 阶段二：迁移工作流

- 解释 migrate dev 与 deploy 的区别。
- 生成并理解迁移 SQL 文件。
- 处理开发环境的迁移冲突。

### 阶段三：Prisma Client 查询

- 完成 CRUD 和批量操作。
- 用 include/select 加载关系并避免 N+1。
- 用聚合、分组和事务完成复杂查询。

### 阶段四：工程化与生产交付

- 实现客户端单例并控制连接。
- 接入 Web 框架并暴露查询 API。
- 配置日志、监控与缓存。
- 执行正确的生产部署流程。

## 2. 排错题

- 连接串或环境变量问题。
- Schema 关系字段未成对。
- 迁移冲突或生产迁移失败。
- 客户端类型过旧。
- N+1 查询缓慢。
- 事务超时或冲突。
- 连接数耗尽。
- 部署后客户端未生成。
- 查询结果缺少关系数据。

## 3. 项目评分

总分 100 分，70 分通过，90 分优秀。参考 [综合实战：博客 API](./project-practice.md)：

| 维度 | 分值 | 评分重点 |
|---|---:|---|
| Schema 建模 | 20 | 模型、关系、约束、索引 |
| 迁移管理 | 15 | 迁移正确性、冲突处理 |
| 查询 API | 25 | CRUD、筛选、关系、分页正确性 |
| 事务与一致性 | 15 | 交互式事务、原子更新 |
| 性能 | 10 | N+1 规避、select、索引、分页 |
| 工程化 | 15 | 单例、连接池、日志、部署 |

## 4. 项目评审问题

- 为什么用 Prisma 而非手写 SQL，边界在哪里？
- Schema 与迁移如何保证多人协作一致？
- 关系查询如何避免 N+1？
- select 和 include 如何选择？
- 什么时候用交互式事务？
- 如何保证原子更新不超卖？
- 连接池如何配置，排队策略是什么？
- 生产迁移失败如何恢复？
- 类型安全如何约束接口入参？
