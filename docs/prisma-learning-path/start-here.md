# Prisma 新手导读

## 适合谁

这套路线适合已经掌握 TypeScript 和基础 SQL，准备用 ORM 提升开发效率和类型安全的开发者。学习重点是 Schema 建模、迁移和 Prisma Client 查询 API，再逐步掌握事务和生产工程化。

## 开始前准备

- 掌握 TypeScript 基本类型和异步编程。
- 了解关系数据库基础（表、行、主键、外键），可参考 [PostgreSQL 学习路线](../postgresql-learning-path/README.md) 的数据库基础部分。
- 了解一种 Web 框架的基本用法（如 Express、NestJS）。
- 能运行 Node.js 和 npm。

```bash
node --version
npm --version
```

## 学习顺序

| 阶段 | 先回答的问题 | 阶段产出 |
| --- | --- | --- |
| 零 | 如何初始化 Prisma 并连接数据库？ | 可运行的最小客户端 |
| 一 | 如何用 Schema 定义模型和关系？ | 完整的数据模型 |
| 二 | 如何管理数据库结构变更？ | 可回滚的迁移历史 |
| 三 | 如何完成增删改查和关系查询？ | 类型安全的查询层 |
| 四 | 如何接入框架并生产部署？ | 生产可用的 API 服务 |

## 每阶段学习方法

1. 每个概念先写最小 Schema 或查询并实际运行。
2. 故意制造迁移冲突，练习解决流程。
3. 用 Prisma Studio 可视化检查模型和数据。
4. 在项目中接入真实查询，观察生成的 SQL。

## 常见排错顺序

```text
安装与连接
  -> 环境变量与连接串
  -> Schema 语法与关系定义
  -> 迁移冲突
  -> 客户端未重新生成
  -> 查询结果不符合预期
  -> 事务与并发问题
  -> 连接池与部署配置
```

## 阶段项目路线

从 [综合实战：博客 API](./project-practice.md) 开始，每完成一个阶段就增加一个能力：初始化、数据建模、迁移、查询 API 和生产部署。

## 完成标准

- 能初始化 Prisma 并连接 PostgreSQL。
- 能用 Schema 定义模型、关系和约束。
- 能用迁移管理数据库结构变更并解决冲突。
- 能用 Prisma Client 完成 CRUD 和关系查询。
- 能用事务保证一致性并接入 Web 框架。
- 完成 [学习评估](./learning-assessment.md) 中的阶段考核与项目评分。
