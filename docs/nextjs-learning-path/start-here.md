# Next.js 新手导读

## 适合谁

这套路线适合已经掌握 React 组件、Hooks、状态管理和基础 TypeScript，准备学习全栈 React 应用开发的人。学习重点是理解 Next.js 如何组织路由、渲染和数据获取，再逐步掌握缓存、鉴权和生产交付。

## 开始前准备

- 能使用 React 函数组件、Hooks、Props 和状态管理。
- 能读懂 TypeScript 类型、泛型和模块导入。
- 能理解 HTTP、JSON、Promise 和浏览器渲染。
- 能使用终端、npm 和 Git。

```bash
node --version
npm --version
```

推荐先完成 [React 学习路线](../react-learning-path/README.md) 的阶段一至阶段三，再开始本路线。

## 学习顺序

| 阶段 | 先回答的问题 | 阶段产出 |
| --- | --- | --- |
| 零 | Next.js 如何启动，目录和开发流程是什么？ | 可运行的初始化项目 |
| 一 | 路由、布局和 Server/Client 组件如何工作？ | 多页面内容站点骨架 |
| 二 | 数据在哪里获取，缓存如何失效？ | 带缓存和 ISR 的列表与详情 |
| 三 | 表单、鉴权和权限边界如何设计？ | 带登录与发布的完整功能 |
| 四 | 性能、测试和部署如何完成？ | 优化并可部署的内容平台 |

## 每阶段学习方法

1. 先理解框架心智模型，再运行最小示例。
2. 每个示例都观察服务端渲染结果与浏览器加载结果。
3. 主动制造一次缓存不刷新、鉴权绕过或构建失败。
4. 完成阶段项目增量，再进入下一阶段。

## 常见排错顺序

```text
开发服务器与端口
  -> App Router 目录与文件名约定
  -> 页面组件默认导出与渲染模式
  -> Server/Client 组件边界
  -> 数据请求位置与缓存策略
  -> Server Actions 输入校验与权限
  -> 构建、路由和部署配置
```

## 阶段项目路线

从 [综合实战：内容平台](./project-practice.md) 开始，每完成一个阶段就增加一个能力：页面骨架、路由布局、数据缓存、鉴权发布、性能部署。每个代码片段都标明上下文，避免把孤立片段误当成完整项目。

## 完成标准

- 能解释 App Router 的路由、布局、loading、error 和 not-found 边界。
- 能根据场景选择静态渲染、动态渲染或 ISR。
- 能设计数据获取与缓存失效策略，并说明理由。
- 能通过 Server Actions 完成变更，并校验输入与权限。
- 能完成测试、部署、监控和回滚验收。
- 完成 [学习评估](./learning-assessment.md) 中的阶段考核与项目评分。
